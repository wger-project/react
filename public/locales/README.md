i18n README
===========

To extract new strings `npm run i18n`, actual translation occurs in weblate:
<https://hosted.weblate.org/projects/wger/frontend/>

More info: <https://react.i18next.com/>

Plural forms
------------

Plural strings use i18next JSON v4 keys. Call the base key with a numeric `count`, for example
`t('measurements.chartRangeMonths', { count: 3 })`. English has `_one` and `_other`, other languages
use the forms they need, such as `_few` or `_many`. The weblate component uses the `i18nextv4` file
format, which groups these keys and offers each language its plural forms.

Use `{{count}}` in `_one` as well instead of a literal `1`: in some languages this form also covers
numbers such as 21.

More info: <https://www.i18next.com/translation-function/plurals>

Please note that the contents of i18n.tsx contains the values of the exercise categories, equipment, etc. and is
autogenerated on the wger repo by the extract-i18n.py script (python manage.py extract-i18n).
